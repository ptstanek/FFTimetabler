# FFTimetabler

Basic class timetabler app. The FF stands for "Very Functional".

## Description

The timetable app my college provided was extremely slow to load and was practically useless. This is my implementation to provide similar functionality. 

## Getting Started

### Dependencies

This project uses yarn + parcel. 
To install the required packages:
`yarn install`

### Executing 

There's a script in the `package.json` file to run this project with HMR.

```
yarn debug
```
